# 远古宝珠设计草案

日期：2026-11-04

所属模组：淬炼之季

状态：设计留档，暂不实施；本文不代表功能已经实装。

## 设计定位

对标天体宝球，提供一种可以搬运、放在地上供附近玩家使用的远古科技物品。

通过两个阶段建立成长路线：击败远古守护者、探索完整远古科技塔后制作残缺遗物；击败织影者后获得修复材料，将遗物升级为完整宝珠。

核心收益是减少重复往返远古的路程，不免除远古配方本身的材料消耗，也不直接跳过首次远古探索。

## 两阶段概览

| 规则 | 残缺的远古遗物 | 远古宝珠 |
| --- | --- | --- |
| 获取方式 | 持有远古钥匙，在完整远古科技塔附近制作 | 向残缺遗物给予织影者的新掉落材料 |
| 提供科技 | 原版残缺远古科技塔对应的配方 | 原版完整远古科技塔对应的全部远古配方 |
| 科技生效条件 | 放在地上，玩家靠近 | 放在地上，玩家靠近 |
| 随身携带 | 可以 | 可以在所在世界内携带 |
| 跨地面／洞穴携带 | 可以 | 不可以，遵循天体宝球一类特殊物品的跨层限制 |
| 数量限制 | 允许多件存在 | 允许多颗存在，每颗都需要单独修复 |
| 主要用途 | 外出携带、跨层使用残缺远古科技 | 在选定的一层建设可搬动的完整远古科技点 |

这里的“世界唯一属性”指与天体宝球相似的特殊物品保护和跨层限制，**不设置整个服务器只能存在一颗的数量上限**。地面和洞穴可以分别拥有完整宝珠。

## 第一阶段：残缺的远古遗物

### 制作条件与消耗

每次制作都必须同时满足以下条件：

1. 制作者自己的物品栏或背包中持有远古钥匙。
2. 制作者位于真正完整的远古科技塔的有效制作范围内。
3. 具备配方要求的消耗材料。

| 物品 | 数量 | 用途 |
| --- | ---: | --- |
| 远古钥匙 | 1 | 制作前置条件，不消耗 |
| 铥矿 | 20 | 制作消耗 |
| 噩梦燃料 | 24 | 制作消耗 |
| 守护者之角 | 1 | 制作消耗 |

远古钥匙只作为资格凭证，不采用“先扣除、制作后返还”的方式。附近箱子或队友身上的钥匙不满足此条件。

配方不会因制作过一次就永久脱离上述条件。残缺遗物和完整宝珠都不能代替真正的完整远古科技塔来制作新的残缺遗物，避免在基地无限复制制作地点。

### 使用方式

- 可以随身携带，也可以自由带上地面、带下洞穴。
- 放到地上后，附近玩家可以使用其提供的残缺远古科技。
- 放在物品栏、背包或箱子里时，不向附近玩家提供科技。
- 收起物品或离开有效范围后，不再提供制作权限；不会因此永久学会这些远古配方。
- 科技由附近玩家共享，不绑定制作者或持有者。

“残缺远古科技”直接沿用原版对应科技范围，不另列一套自定义配方。原版范围本身已包含建造护符、拆解魔杖等实用品，因此残缺阶段具有独立价值。

## 第二阶段：修复为远古宝珠

### 修复材料

为织影者增加一种额外掉落物，保留原有掉落。

- 最初占位名：`？？？`。
- 当前建议名称：**远古精魄**，暂定，未最终定名。
- 定位：使残缺遗物恢复完整的核心材料。
- 必须允许跨地面与洞穴携带，让玩家能自行选择宝珠的修复地点。
- 掉落数量、概率及每次修复的消耗数量，留待实施前确认。

### 升级流程

1. 玩家取得织影者掉落的修复材料。
2. 将残缺遗物和材料带到希望长期使用完整远古科技的那一层。
3. 将残缺遗物放在地上，给予修复材料。
4. 消耗材料，把该遗物升级为完整的远古宝珠，不额外复制物品。
5. 宝珠开始提供完整远古科技，同时获得跨层携带限制。

给予材料前应能看到简短提示，例如：**“修复后无法跨地面与洞穴携带。”** 让玩家在升级前知道地点选择的影响。

### 完整形态规则

- 在所在世界内仍然可以拾取、携带、移动和重新放置。
- 只有放在地上时才提供完整远古科技，附近玩家均可使用。
- 不能随身跨地面／洞穴搬运，也不能利用模组的跨世界容器交换绕过限制。
- 沿用原版远古制作的材料要求，不提供免费制作或永久学习远古配方。
- 每一颗完整宝珠都需要独立制作残缺形态并消耗修复材料。

## 平衡考虑

- 远古钥匙和守护者之角把制作门槛绑定到远古守护者进度；完整科技塔要求保留探索和现场制作的意义。
- 残缺阶段兼顾便携和实用性，完整阶段增加科技范围，但需要玩家选择常驻世界。
- 残缺遗物可以继续用于跨层旅行，不因完整宝珠出现就失去用途。
- 完整宝珠允许多颗存在，使多人服务器能逐步在不同世界建立科技点，也给重复挑战织影者留下收益。
- 先保留当前配方数值，后续根据实际获取成本和使用体验调整。
