# 穿越世界快速版

日期：2026-11-03。分支：`codex/instant-world-exchange`。代码已接入 `content/` 并同步本地游玩模组，重启双层后使用现有穿越功能即生效；未上传创意工坊，版本号暂不变。

## 玩家行为

- 保留原按钮和双方整箱互换；锁箱、格位、堆叠、耐久、物品校验及重复消息保护继续保留。
- **一次穿越不请求世界存档。** 正常路径只等待双方准备、应用和完成确认，然后解锁。
- 首次建立双层保护、正常自动／手动保存、正常退出仍会保存。玩家首次出现还会写入独立的恢复记录，这不是每次穿越保存世界。
- 地面和洞穴须一起更新并重启。当前协调器面向地面＋洞穴两层；不支持三层以上共同交换。

## 保存顺序

1. 暂停发起新交换、玩家迁移和原生物品迁移，等待已开始的操作及玩家归属确认结束。
2. 双方核对玩家归属，各自调用一次原生世界保存；捕获该次保存实际序列化的世界和玩家记录。保存之后的退出、背包写入不能改写这份捕获结果。
3. 将世界正文写为独立备份；保存玩家记录、空记录和共同检查点编号。正文和清单均读回校验。
4. 双方确认备份完整，再分别提交检查点；提交采用交替清单及最后写入的校验指针。双方完成后开放交换或继续退出。

保留最近 **8 个**共同检查点。备份以 `swx2_<世界会话>_*` 命名，保存在对应分片的原生持久化目录；不要只备份世界快照而遗漏这些文件和玩家目录。

正常退出在原生 `OnDespawn` 清理玩家之前建立共同检查点；清理后的关闭回调不再重复保存另一份世界。双方先后退出复用已经完成的同一检查点。如果对端已经离线，允许退出并保留已有共同检查点，下次按异常恢复处理，不把单层的新进度冒充双方已保存。

## 异常恢复

- **短暂断线，同一进程重连：** 保留在途事务与锁箱，握手通过后继续；不因短超时补发旧物品。通信使用逐帧累计的墙钟时间，暂停模拟时仍能重试，并检测失去回应的对端。
- **任意一层进程重启：** 暂停操作，协商双方最近可验证的共同检查点；仍在运行的另一层也重新加载对应世界。恢复整个世界和玩家状态，不单独补回箱内物品。
- **玩家恢复：** 世界加载前先验证独立备份。原生加载玩家前清理较新的原生快照，然后通过原生玩家接口写回记录；新增玩家在对应旧检查点使用空记录。玩家离线首次回来时补记原状态，迁移前等待双方记录齐全，迁移确认携带唯一编号。
- **手动回档：** 在保留范围内选择较早检查点时，两层一起对齐，后续检查点退出当前时间线；同时恢复对应原生快照及元数据、截断之后的物理快照。回到快速版安装前时，先归档原快速版清单，再共同加载原生旧快照并完成旧事务。详见[回档修复记录](穿越世界回档启动失败_修复记录.md)。不能把一层的新人物数据与另一层旧世界混用。
- **备份缺失、校验失败或无法找到共同检查点：** 停止放行，不自行猜一个旧状态。原生世界／索引损坏不属于已验证的自动修复范围；保留日志、原始目录和 `swx2` 备份排查，不能清空组件或保护记录来强行解锁。

**代价：异常恢复会撤销最近共同检查点之后的游玩进度，包括已取出、消耗、合成的物品及角色变化。** 这是取消逐次存档后的恢复规则，并非保证断电前最后一笔进度永久保留。

旧版未完成的持久化事务先按旧协议收尾，然后切换快速版。关闭容器按钮配置仍保留既有恢复记录的加载；直接卸载模组、修改原生保存接口或绕过容器接口的其他模组不在此保护承诺内。

## 验证

| 项目 | 结果 |
| --- | --- |
| 最终真实双层测速 | 0.400 / 0.400 / 0.433 秒，中位约 0.40 秒 |
| 穿越期间世界保存 | 三轮均验证为 0 次 |
| 旧协议与容器适配回归 | 518＋75 项断言通过 |
| 快速协议、检查点与恢复回归 | 117 项断言通过 |
| 单层强制关闭 | 交换并修改背包后，仅关闭洞穴；重启洞穴，地面自动对齐，双方世界、原玩家背包及新增玩家空记录验证通过 |
| 正常退出再启动 | 共同保存后退出，重新启动保留交换后的世界标记和背包产物 |
| 保存中断窗口 | 洞穴原生世界已写入、独立备份提交前强制关闭；双方自动恢复至上一共同检查点，世界与玩家校验通过 |

测速使用本机独立小型地面／洞穴专用服务器、约 32 KiB 附加物品记录；终点为事务完成并解锁，包含堆叠、格位和耐久校验，不包含启动和首次共同检查点。此前两次存档版本同类测试中位约 2.83 秒。公网、负载和大存档会影响实际耗时。

恢复实测使用服务端生成的模拟玩家，覆盖原生玩家文件的读写与重启加载。**真实多人客户端迁移、房主在洞穴退出及第三方保存接口兼容尚未实机验收**；迁移编号、归属、迟到确认及保存屏障已有模拟回归。正式玩家存档未用于破坏性测试。

## 代码与复现

- `worldexchangeinstant2hm.lua`：不逐次保存的 v2 事务协议。
- `worldexchangecheckpoint2hm.lua`：双方检查点与玩家归属协调。
- `worldexchangestore2hm.lua`：独立备份、提交、验证和保留。
- `worldexchangeengine2hm.lua`、`easy_other/worldexchangefast.lua`：原生加载、保存、玩家及退出接入。
- `components/worldexchange2hm.lua`：容器、分包、握手、暂停时通信和状态提示。

测试入口及隔离夹具见 [tests/README.md](../tests/README.md)。本机原生日志保存在被 Git 忽略的 `work/world-exchange-runtime/`，不随工坊发布。

代码回退与存档回退需配套进行：已经产生快速版检查点的存档，不宜只替换回旧 Lua 文件继续加载较新的玩家文件。保留完整双层存档、模组代码及独立备份，再选择一致的恢复点。
