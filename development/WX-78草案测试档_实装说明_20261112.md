# WX-78 草案测试档

2026-11-12，已随工坊版本 **2.8.15.0.30** 发布，线上版本、完整日志与下载包已核验。设计依据为 `WX-78重构方案_草案_20261111.md`；本次按用户要求改为可选测试档，保留旧实现。

## 玩家设置

原 WX-78 简单、困难开关合并为“WX-78方案”，配置键 `WX-78 Mode`：

| 档位 | 行为 |
| --- | --- |
| 当前方案（兼容旧档），默认 | 完整保留原简单、困难总开关、角色总开关及 WX-78 两个旧开关的组合；新选项缺失时也走此档 |
| 旧方案·简单 | 加载原 WX-78 增强，不加载角色困难改动 |
| 旧方案·困难 | 加载原 WX-78 增强及角色困难改动 |
| 草案测试 | 仅加载新电路增强和进食回电，恢复、技能树和其他电路沿用当前游戏与已启用模组 |
| 关闭改动 | 不加载淬炼 WX-78 增强或角色困难改动，保留旧物品恢复 |

手动选择的四个档位独立于简单、困难及角色总开关。旧子项仅对旧方案生效。旧 `wx78_easy`、`wx-78` 仍保留在配置 schema 中读取存档，但从本模组设置界面隐藏，保存其他设置时保留原值。默认档不会拆分融合芯片、迁出芯片箱或重算旧齿轮属性。

这里是世界模组设置，决定该世界全部 WX-78 的实现，不是角色游戏内的即时切换按钮。

## 草案规则

- 激活的小／大血量电路固定格挡 2／5；Alpha II 后 3／7.5，合计最多 20。先扣固定值，再计算护甲；原生 Alpha II 血量电路百分比减伤被替换。位面伤害、非战斗扣血及原生护盾继续按各自规则结算。
- 小／大理智电路的负光环剩余倍率：无 Alpha 为 0.9／0.75，Alpha I 为 0.8／0.5，Alpha II 为 0.75／0.4；电路乘算，最低剩余 0.2。装备、亲和、其他模组独立来源继续叠加。
- 小理智电路每块每分钟恢复 1 理智；大理智原有的持续恢复移至小电路。保留原生最大理智、服装回理智技能和其他理智来源。
- 进食每累计实际补入 45 饥饿恢复一格电，135 对应三格。不足 45 的余量保存；饱食溢出不计；满电不存余量；自带非零 `chargevalue` 的电力食物仅走原有回电。不增加充电技能倍率。
- 饥饿及其余电路、六／七格槽位、拆装、扫描、躯体、无人机和亲和维持原有基础。不加载旧融合、齿轮永久属性、组合领域、超载、食物负效果反转、无人机倍率与双亲和增强。
- 附身躯体的电路使用原生跟随者技能来源，保留躯体自身的光环系数。

## 存档与物品

恢复代码独立于旧玩法加载。进入没有融合增强的档位时，旧 Lv N 电路保留本体并返还 N−1 块同种普通电路，保留当前耐久／燃料比例；已安装本体继续安装，额外电路进入背包，满包落地。未完成返还数量独立保存，处理前再次保存也不会丢失。

旧虚拟芯片箱恢复其保存物品至背包，满包落地，成功恢复一项才清除对应记录。无法生成的物品保留记录并重试。超过当前栏位上限的芯片原样退回，不收取拆卸耐久或电量；默认档不运行此处理。

旧版离线／跨层过程中暂存的扫描仪记录也会独立恢复为随从；处理前再次保存仍保留记录，成功生成后才清除。

草案／关闭档的上限由原生激活流程重新建立，不继承旧齿轮／融合加成；旧保存的当前三维仅在超过新上限时裁剪。原生吃齿轮计数继续保留。切回旧档后已拆开的电路维持普通电路，不自动融合或重复返还。

## 实现入口

- `content/scripts/wx78config2hm.lua`：统一解析档位与旧配置。
- `content/common/wx78_mode.lua`：互斥加载与旧配置兼容。
- `content/scripts/wx78draft2hm.lua`：新玩法，保留原生电路回调及技能订阅。
- `content/common/wx78_recovery.lua`：融合、栏位、虚拟箱和回电余量保存恢复。

新增脚本已纳入原生 ManifestManager 启动注册和 `mod.manifest`。

## 验证入口与边界

`tests/run_wx78_modes_tests.py` 覆盖 64 种旧配置组合以及每组四种显式档位、数值三档、上限、电路停电、营养换算与 Lua 编译。`run_wixie_tests.py` 使用原生配置收集代码检查合并开关及隐藏旧值保留；`run_mod_config_layout_tests.py` 检查设置布局。

`tests/run_native_wx78_modes.py --edition solo|stable|beta --mode draft|legacy|easy|hard|off` 在独立专服用真实组件验证加载、护甲前格挡和位面伤害、技能档位、停电、进食收益、躯体继承、融合拆分、虚拟箱、栏位退回及重复保存加载。`--roundtrip` 先用实际旧方案建立融合电路、齿轮和芯片箱保存记录，重启切至草案，再重启切回旧方案。`legacy` 测试刻意不写新配置键，核对缺省加载。

测试使用构造角色、注入技能状态和隔离存档；不代表真实客户端自然加点、界面操作、跨层旅行或玩家旧世界长期游玩验收。最终结果见 `development/validation/wx78-modes-20261112.txt`。
