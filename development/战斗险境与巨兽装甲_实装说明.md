攻击端按来源拆分基础伤害 → 合并适用正向倍率（含克制）→ 渐进压缩一次 → 负面倍率与 PVP 系数 → 按原接口语义处理固定加值 → 原有目标防御 → 生命组件减伤及原有单次上限 → 动态装甲单次 10% 最大生命上限 → 连续动态减伤 → 最终实际掉血积累动态值。

### 自定义武器适配入口

可在 `weapon.components.weapon.progressiveterms2hm(self, attacker, target)` 返回：

```lua
return {
    regular = {{amount = 100, factors = {2, 1.5}}},
    special = {planar = {{amount = 20, factors = {2, 1.5}}}},
}
```

`amount` 为尚未乘这些因子的该项伤害，`factors` 包含该武器项自身适用的倍率及武器克制，各一次；角色适用倍率由外层收集。固定加值若不吃某个组件倍率，作为不含该倍率的独立项返回。此接口替代该次武器 `GetDamage` 取值，适配方负责保留必要副作用，不能再返回已重复乘算的总值。
