# 眼球炮塔加强

2026-11-03，本地开发版，尚未发布创意工坊。

## 开关与数值

沿用「简单模式 → 建筑改动 → 眼球炮塔加强」开关，默认开启。关闭后不加载本次加强，配方、属性和攻击回到游戏及其他模组的规则。

| 项目 | 开启后的效果 |
| --- | --- |
| 配方 | 原有材料额外增加 **2个羊角**（`lightninggoathorn`），包括永不妥协的 Wathom 专用替代配方；已放置炮塔的分解材料同步增加羊角 |
| 生命 | 最大生命 **2000**，新放置时满血；已有炮塔按正常存档血量加载，再逐渐回复 |
| 回复 | 每秒 **50**，不超过最大生命，不复活已死亡炮塔 |
| 基础攻击 | **200点普通伤害，带电击属性**，普通生物和Boss使用相同基础值 |
| 连锁 | 首个目标之外最多 **4个**；每跳寻找上个目标 **6距离**内最近的合格敌人；每个目标一发仅命中一次 |
| 安全筛选 | 连锁排除玩家、建筑、墙、炮塔、工程设施、友军、玩家随从及中立生物；不改变原有首个目标的索敌规则 |
| 原有护盾 | 保留33%和66%附近的两段护盾，持续10秒、各自冷却60秒；取消原版加强中“刚放置仅10%血”的规则 |

旧文案中的“死亡返还炮塔”没有对应实现。本次保留实际原生掉落，不新增返还规则。

## 伤害顺序

原生炮弹实际命中 → 对命中的冰川座狼执行专属秒杀检查 → 其他目标按原生战斗流程结算 → 附加隔离火焰 → 向下一名合格目标连锁。

普通目标每跳计算：

`基础200 × 电击倍率 × 原生攻击侧修正 × 0.8^跳数 → 该目标的护甲、抗性、巨兽装甲等受伤侧处理`

首个目标跳数为0。链伤基础值依次为 **200 / 160 / 128 / 102.4 / 81.92**；每个目标单独计算电击和防御，不根据上一个目标实际掉血量推算。

原生电击默认倍率为 `1.5 + 潮湿倍率`：干燥、无防御目标的五段伤害为 **300 / 240 / 192 / 153.6 / 122.88**，完全潮湿目标电击倍率为2.5。电击免疫目标不享受上述电击增伤。200是基础面板值，不是最终固定掉血，也不是另加一份200电伤。其他模组修改电击倍率时沿用修改后的值。

普通伤害经过原生 `Combat:DoAttack`，因此保留护甲、闪避、反应、仇恨和本模组动态巨兽装甲等处理。玩家的战斗险境倍率规则不额外套给炮塔。

## 材料升级

**已放置炮塔、地上的眼球塔物品、物品栏内的眼球塔均可升级。** 每种升级消耗 **1个**对应材料：

- **龙鳞皮 `dragon_scales`**：攻击命中的可燃生物获得隔离火焰，持续8秒，基础每秒5点火伤；重复命中刷新时间，多座塔不叠加同一种火焰。
- **蘑菇皮 `shroom_skin`**：免疫原版 `sporecloud` 和永不妥协 `sporecloud_toad` 孢子云；不同时免疫其他伤害光环。

已放置炮塔和地上物品沿用“给予”；物品栏内先拿起材料，再对眼球塔格子右键“给予”，支持原生背包动作流程。

两种升级可共存并写入物品／炮塔原生存档，重新加载恢复。重复给予已完成的升级会拒收，不消耗材料。**升级后的物品放置时自动继承全部升级**；也可以先升级一种，放置后再给予另一种。

放置仍调用原生部署回调，通过部署期间的局部上下文把状态交给新炮塔，不替换皮肤、碰撞或摆放逻辑，不额外保存世界。部署返回或异常时清理上下文，避免后续无关炮塔继承；部署未成功消耗物品时，原物品保留升级。

隔离火焰使用独立视觉实体，只对附着生物调用原生火伤结算，尊重火伤抗性和无敌。它不调用原版 `Burnable:Ignite`，不添加热源、传播器或原版 `fire` 标签，因此不会给建筑、墙、树木、地面物品或其他生物传热、点燃或造成火焰溅射；也不触发原版燃烧状态的烤熟掉落等附带行为。临时火焰不写入存档，重载时结束。

部分植物生物受电击后会自行调用原版点燃，包括退出电击状态时的延迟点燃。本次拦截**来源是加强炮塔**的这类调用：有龙鳞升级时转为隔离火焰，没有升级时不点燃；其他来源的正常燃烧不受影响。生物自身独立的死亡爆炸等技能仍保留。

## 冰川座狼专属秒杀

仅匹配永不妥协的 **`glacialhound`**，首个炮弹命中和后续链伤命中均生效。该实体的冰盾通过 `health.redirect` 转移伤害，原生 `ForceKill()` 也可能被转移，所以使用 `Health:SetVal(0, "eyeturret", attacker)`，跳过伤害重定向、无敌和减伤，保留原生死亡事件、死亡状态、掉落及击杀归属。

其他猎犬、普通座狼、其他冰盾单位和Boss没有此秒杀特例。

## 验证

- `tests/run_eyeturret_tests.py`：115项检查，调用本机原生炮弹命中、攻击、电击、火伤、给予动作收集和死亡实现；场景实体与引擎调度有模拟部分。包含物品升级、背包右键入口、保存、部署继承、混合升级、重复材料与部署失败隔离。
- 科技建筑配方预览40项、动态巨兽装甲118项、渐进战斗险境105项回归通过。
- 独立原生专用服务器：开启／关闭配置、五段链伤、每秒回复50、两种材料的原生“给予”动作及升级、受伤实体保存恢复、两类孢子云、带原生冰盾和无敌的冰川座狼死亡及掉落、可被电击自动点燃的生物旁建筑防火。补充原生玩家背包格子的动作选择与执行、单个材料消耗、物品保存、原生部署继承及放置后再次保存。

原生夹具是 `tests/native/eyeturret_fixture.lua`，仅可导入名称为 `ShadowWorld isolated eyeturret test` 的一次性独立世界。不得导入正式玩家存档。
