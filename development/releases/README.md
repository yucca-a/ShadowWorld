原始 2.8.14.95 在恢复时已按 Steam 清单的 SHA-1 校验全部 432 个文件。本次建仓重新检查归档 CRC、文件数量和大小，并生成 SHA-256 清单；历史归档本身的 SHA-256 记录于 `snapshot-provenance.json`。

2.8.14.96.1 相对 2.8.14.96 只有 `modinfo.lua` 变化，包含更名、分支说明和版本号，玩法代码相同。当前版本使用 `.gitattributes` 禁止自动换行转换。前两个标签仅含历史源码，恢复或导出时应设置 `core.autocrlf=false`，以保留已发布文件的原始字节，具体命令见 [版本回退说明](../版本回退说明.md)。
