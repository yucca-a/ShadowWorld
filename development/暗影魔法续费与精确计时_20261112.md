# 暗影魔法续费与精确计时

2026-11-12，已随工坊版本 **2.8.15.0.30** 发布，线上版本、完整日志与下载包已核验。沿用“暗影操控器兑换暗影魔法”配置，不新增开关。

## 收费与入口

暗影操控器和绑定它的清洁扫把采用同一套交易回调：给予噩梦燃料，一次补满至 **20 个游戏日**。

```text
费用 = 向上取整((20天 − 当前实际剩余时间) ÷ 5天)
新截止时刻 = 当前游戏时刻 + 20天
```

| 剩余权限 | 需要燃料 | 付费后 |
| --- | ---: | --- |
| 尚未兑换／已经过期 | 4 | 完整20天 |
| 5天 | 3 | 完整20天 |
| 10天 | 2 | 完整20天 |
| 14天 | 2 | 完整20天 |
| 15天 | 1 | 完整20天 |
| 19.25天 | 1 | 完整20天 |
| 恰好20天 | 0，不接受续费 | 保持原期限 |

“不足5天按5天收费”包含一天中的不足整天部分。例如剩余15天零一秒与剩余15天少一秒，会落在不同收费档。期限按实际时间计算，不把显示或估算的整天数作为收费依据。

只从给予的那一叠材料中扣除所需数量，不扫取背包里的其他燃料。材料不足时拒收，不部分扣款；大堆材料只拆出应扣数量。不会将不足5天的付费余量囤到20天上限之外。成功／不足／无需续费均有简短角色提示。

天生已具有全部相关权限、读书消耗也无需降低的角色不需要付费购买相同能力。

## 清洁扫把

原扫把会复制绑定建筑的 trader 回调和 AcceptGift 方法，因此动态计算费用的位置同时适用于建筑和扫把，不复制收费实现。

增加定向的右键“给予”入口，仅作用于噩梦燃料与暗影操控器、已绑定 `researchlab3` 的扫把。保留原有左键交互；未绑定扫把、绑定一本／二本／三本的扫把不获得这一续费入口。骑乘限制按原生给予习惯处理，绑定标记与右下角科技图标继续使用原实现。扫把在背包和地上都可使用，保存恢复的绑定也使用相同收费规则。

## 连续计时

`shadowmagic2hm.lua` 统一管理权限：使用服务器时钟 `clock:OnSave()` 一次读取的周期、当前阶段及阶段进度，计算连续游戏时间。天数和日内进度取自同一份权威快照，避免天亮时复制状态字段先后更新带来的短暂时间回跳。

截止时间保存在玩家 `persistent2hm.data.shadowmagicexpires2hm`。换日只减少实际经过的时间；保存、重载及跨层携带该字段，不重新发放20天。世界停机／暂停时游戏时间不推进；玩家离线而世界继续运行时，权限按世界游戏时间到期。

只对有有效临时权限的玩家安排到期检查，平时最多每秒检查一次，剩余不足一秒时按剩余时间安排。读取权威时钟也能处理睡眠、跳时等造成的游戏时间跃迁；这类跃迁在下一次检查时撤回过期能力。无记录或已经到期的玩家不保留循环检查。

临时授予的暗影魔法标签、魔术工具标签、magician 组件及读书倍率会在到期时撤回。首次兑换前已存在的标签／组件会保留，续费不会误把本次临时授予的能力记为角色天赋。原生 magician 组件移除时会自行删除 magician 标签，因此额外恢复兑换前已有但不依赖该组件的标签。

## 暗影秘典

保留成功补燃料一次续 **1天** 的原有换算。它仍要求玩家曾经兑换过权限，不负责首次开通。已过期时恢复完整一天，不再仅持续至下次换日；未到期时加一天，统一封顶20天。书本的原有补燃料消耗和恢复量不变，续费按成功操作次数计算。

## 旧存档

原 `shadowmagiccycle` 没有记录兑换时刻的小数部分，无法重建当时的准确时刻。首次读取时，保留按原日期能推算出的剩余天数 `clamp(20 − 天数差, 0, 20)`，从迁移时刻开始换成连续截止时间。此前通过秘典囤积超过20天的记录迁移为最多20天；过期记录不自动赠送期限。

新截止时间存在后不再反复迁移。原日期字段保留为“曾经兑换过”的兼容标记，供扫把绑定、魔术帽等现有机制识别；它不再参与新权限的到期或续费计算。

- `content/scripts/shadowmagic2hm.lua`：时钟、迁移、收费、临时能力生命周期及秘典续期。
- `content/easy_other/easy_structures.lua`：实际交易、右键动作、秘典回调和原有扫把绑定入口。

`tests/run_shadowmagic_tests.py` 检查收费、换日、封顶、旧档迁移、秘典续期及原有能力清理。`tests/run_native_shadowmagic.py --edition solo|stable|beta [--restart]` 在隔离专服运行真实给予动作、材料拆分、绑定扫把保存加载、连续计时、自然到期、秘典和角色能力恢复；`--disabled` 检查原选项关闭。`--restart` 同时保存世界时钟及角色记录，再冷启动核对截止时间和剩余量。

这些测试使用原生实体、动作收集器和构造角色，不代表实际联网客户端鼠标操作或玩家旧世界长期游玩验收。详细结果见 `development/validation/shadowmagic-renewal-20261112.txt`。
