# 天行健 0.2.6

独立的饥荒联机版客户端模组，用于自己的单人测试世界，与淬炼版无依赖关系。

## 使用

把整个 `vanilla_solo_assist` 文件夹放入游戏 `mods` 目录，在游戏的“客户端模组”中启用“天行健”。无需在世界的服务器模组列表中启用。

- **F6**：循环切换移动档位：**关闭 → 温和 → 加速 → 极速 → 关闭**。进入世界默认关闭；方向键／WASD、鼠标左键点地和按住左键拖动都使用当前档位。无需手动开启游戏的移动预测设置。
- **温和**为较小提速档，已校准鼠标移动预测下的卡顿；**加速**沿用0.2.4的快速档；**极速**沿用0.2.5提高后的快速档。档位不代表固定实际倍速。
- **F7**：开启或关闭自动解控，默认关闭。开启后检测冻结、昏睡、受击、触电、击退及束缚等控制动作，自动通过短暂搓手恢复行动。再次按下关闭。
- 在模组设置中，可以分别更换“移动档位切换按键”和“自动解控开关按键”，支持F1–F12、A–Z和数字0–9。原来的固定移动档位选项已移除，直接按键轮换即可。
- 两项绑定相同按键时，每按一次移动进入下一档、自动解控切换一次开关；长按或键盘重复按下不会连续跳档。
- 按移动切档键，仅在自己角色头顶显示当前移动档位；按自动解控键，仅显示自动解控状态，约2秒后隐藏。两项绑定同一按键并同时触发时才合并显示。提示是本机非联网标签，不发送聊天，不调用角色说话；其他玩家不可见。
- 聊天输入和菜单中不处理这些开关，建议避开移动、聊天等已有快捷键。
- 打开菜单、聊天输入或站到船上时暂停快速移动；没有方向输入或鼠标行走目的地时不推进位置。
- 鼠标加速只接管原版识别出的纯点地行走，不接管采集、攻击、物品使用等交互。到达后停止；拖动松手、开始交互、改用WASD或将移动档位切到关闭时，清除原来的鼠标加速目的地。温和、加速、极速之间切换会保留当前鼠标行走目标，切到关闭才清除。进入非关闭档位后重新点地即可使用。
- 绕路复用原版Pathfinder接口，等待寻路时不向障碍物直线加速；找不到路线则停止附加加速，让原版处理剩余动作。

自动解控按明确的控制状态判断，不把普通“忙碌”视为受控，因此不会仅因制作、攻击或交互而触发。每次尝试之间至少间隔0.8秒，给原版动作和同步留出时间；关闭开关后停止新的自动尝试。

解控打断的是角色控制动作。冻结组件的计时仍由原版管理，不提供免伤或持续免疫。只有已经探索、当前可见的当前位置才能提交对应地图动作。

## 实现与验证

客户端恢复行动使用原版地图动作入口；不是制造实际物品，不消耗制作材料。快速移动使用原版移动预测与瞬时检查动作的位置校正。单人主机如果直接持有角色实体，则使用原版移动速度接口。

已经在本机原版762172的独立离线专服和真实非管理员客户端中验证对应效果。测试服务器仅布置控制场景和记录位移，没有实现辅助功能。没有改动原版服务器方法或淬炼版。

核心交付代码已加载到真实客户端测试。地图可见条件由真实玩家提供，未使用假地图可见状态。冻结、昏睡、击退测试后，服务器记录到实际跑动。快速档的速度受角色、地形和连接状态影响；不把它描述为固定倍数。

自动解控的状态识别：在没有加速协商、且关闭移动预测的情况下，部分控制状态同步信息不足，识别范围可能受限。

这不证明视频作者使用的是相同方法。特殊角色、骑乘、复杂地形和其他模组组合尚未完整验证。

## 文件

`modinfo.lua`：客户端模组声明、档位和按键配置。

`modmain.lua`：随本地玩家HUD创建时安装辅助。

`scripts/soloassist2hm.lua`：控制状态检测、开关按键、原版请求、输入方向和退出清理。

完整测试记录保存在工作区 `work/client-assist-audit/` 与 `development/validation/vanilla-solo-assist-auto-validation.json`。

0.2.1验证补充：自定义F8/F9绑定、原按键不再生效、按键长按防重复、自动解控开关、正常制作不被打断，以及关闭后冻结不自动解除。按键通过原生输入事件测试，未额外做物理键盘操作验收。

0.2.1 修复启动崩溃：按键列表改为静态数据，避免在原版 modinfo 的空环境里调用 string.char／tostring。回归测试改用安装游戏的实际 InitializeModInfo 与 RunInEnvironment，不再用普通 Lua 全局环境代替。

0.2.2 修复进入世界时的 owner=nil：等原版 PlayerHud:SetMainCharacter 完成角色设置后再挂载。测试已改为真正启用完整模组进入世界，不再由测试脚本手工调用 Attach。头顶提示已在真实游戏窗口按F6并截图确认。

0.2.3 修复移动预测关闭时加速请求被拒绝：只在实际加速期间临时协商服务器所需的请求状态，停止、暂停或关闭后恢复；不修改Profile/client.ini，不添加本地预测组件。原本已经开启预测的连接不额外切换。已用实际关闭预测的真实客户端验证加速和还原。

0.2.4 接入鼠标点地和按住左键拖动的快速移动，复用原版WALKTO动作与Pathfinder寻路接口；到达、松开拖动或改用其他操作时清除鼠标加速目的地。到达时清理原版预测移动并发送停止请求，避免仍有移动指令残留。

0.2.5 提高现有“快速”档的移动速度：客户端每帧位置校正尝试由4次提高到8次，为原版移动和交互留出请求余量；“温和”档维持原值。原有快速档配置自动生效，无需改绑按键或增加开关。直接持有角色实体的主机使用原版速度接口，从3.5倍提高到5倍；这不是对远程客户端实际倍速的承诺。

0.2.6 将F6改为“关闭→温和→加速→极速→关闭”循环切档，头顶提示只显示此次按键触发的功能；自动解控仍由F7独立切换。温和档略调高客户端校正频率以改善鼠标预测移动下的卡顿，主机倍率仍为1.8；0.2.4的快速参数和0.2.5的增强参数分别作为加速和极速。移除重复的固定档位配置，保留两项按键绑定。
