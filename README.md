## 目录

| 目录 | 内容 |
| --- | --- |
| `content/` | 完整模组源码和资源；工坊上传目录 |
| `client_mods/`、`server_mods/` | 独立客户端辅助模组、服务端防护模组及测试 |
| `wiki/` | 已发布百科的源码、资料快照及静态发布目录 |
| `workshop/` | 标题、介绍、封面和更新日志 |
| `tests/` | Lua 5.1 回归测试及 Python 入口 |
| `development/` | 实装说明、暂缓方案、版本校验与恢复说明 |
| 根目录的方案 Markdown | 巨兽装甲、战斗险境等设计说明 |

`work/`、`backups/`、测试依赖和临时日志仅留在本机。已核验的历史源码另存为 Git 标签，可以从仓库独立恢复。仓库不包含玩家世界存档。
